# Panel móvil (antes «Contenido móvil»)

App web personal para ver la bóveda de Obsidian desde cualquier dispositivo:

- **Hoy** (pantalla de inicio): las tareas del «Plan del día» de la nota diaria (se marcan desde aquí), lo pendiente de ayer, lo que se publica en los próximos 7 días, los proyectos activos y el panel de negocio.
- **Contenido**: las fichas `tipo: contenido`, por fase.

- Lee y escribe las notas directamente en el repositorio privado de la bóveda mediante la API de GitHub.
- Este repositorio solo contiene el código: ninguna nota ni clave.
- El token (fine-grained, solo `Contents: Read and write` sobre el repositorio de la bóveda) se guarda únicamente en el navegador del móvil.
